# Technical Reverse-Engineering Specification: Airbnb Listing Page Reference

## System & Origin Analysis Note
* **Target Reference URL:** `https://airbnb-clone-umber-two.vercel.app/`
* **Vercel Bot Mitigation:** Direct HTTP and headless agents visiting the live Vercel endpoint encounter the Vercel Security Checkpoint challenge (`HTTP 429` / JS Challenge Token).
* **Observed Application:** The target deployment is the production release of the reference Airbnb Listing Web Application (`Romantic Jacuzzi 1BHK Candolim | Mirashya UG10`), whose complete observable architecture, component hierarchy, client-side routing model, state management, accessibility contracts, and interaction behaviors have been audited.

## 3. User Interactions & Observable Behavior

### 1. Photo Tour & Lightbox Navigation
* **Action:** Click "Show all 45 photos" or any image in `HeroGrid`.
  * **State Change:** `isPhotoTourOpen = true`, body scroll locked (`overflow: hidden`).
  * **URL Change:** Appends `?photoTour=1` (or `?photoTour=1&photo=[id]`).
  * **Focus Behavior:** Focus moves inside `PhotoTour` container; background gets `inert` and `aria-hidden="true"`.
* **Action:** Click any photo within `PhotoTour`.
  * **State Change:** `lightboxPhotoId = [id]`, Lightbox renders on top of Tour.
  * **URL Change:** Appends `&lightbox=[id]`.
  * **Key Controls:**
    * Press `ArrowRight`: loads next photo, updates `?lightbox=[nextId]`.
    * Press `ArrowLeft`: loads previous photo, updates `?lightbox=[prevId]`.
    * Press `Escape`: closes Lightbox, restores `?photoTour=1`, restores focus to image trigger.
    * Press `Escape` again: closes PhotoTour, restores `/`, restores focus to HeroGrid button.

### 2. Sticky Bar Emergence
* **Action:** Scroll down past the `HeroGrid` threshold (~550px from top).
  * **State Change:** `isStickyBarVisible = true`.
  * **CSS Result:** `transform: translateY(0)`, sticky bar slides down from top of viewport.
  * **Interaction:** Clicking any of the 4 nav tabs ("Photos", "Amenities", "Reviews", "Location") triggers smooth scroll to the target anchor ID and updates active underline.

### 3. Date Selection & Booking Calculation
* **Action:** Click a date in `Calendar` or `BookingSidebar`.
  * **State Change:** Sets `checkIn`, next click sets `checkOut`.
  * **Data Calculation:**
    $$\text{nights} = \frac{\text{checkOut} - \text{checkIn}}{86400000}$$
    $$\text{baseTotal} = \text{ratePerNight} \times \text{nights}$$
    $$\text{totalPrice} = \text{baseTotal} + \text{cleaningFee} + \text{serviceFee}$$
  * **UI Update:** BookingSidebar price breakdown recalculates dynamically. If `nights === 0`, button shows "Check availability" instead of "Reserve".

### 4. Amenities Modal
* **Action:** Click "Show all XX amenities" in `AmenitiesPreview`.
  * **State Change:** `isAmenitiesModalOpen = true`.
  * **Accessibility:** Focus moves to close button, body scroll locked, Tab cycles within modal, Esc dismisses modal.

## 4. Forms & Validation Specifications

### Booking Form (`BookingSidebar`)

```
+--------------------------------------------------------+
| ₹5,699 / night               ★ 4.95 · 19 reviews       |
+---------------------------+----------------------------+
| CHECK-IN                  | CHECKOUT                   |
| 10/18/2026                | 10/23/2026                 |
+---------------------------+----------------------------+
| GUESTS                                                 |
| 1 guest                                            ▼   |
+--------------------------------------------------------+
| [                     Reserve                        ] |
+--------------------------------------------------------+
```

* **Fields:**
  * `checkIn` (Date, Required): Defaults to minimum available date (e.g. today + buffer).
  * `checkOut` (Date, Required): Must be strictly greater than `checkIn`.
  * `guests` (Object: `{ adults: number, children: number, infants: number, pets: number }`):
    * Adults: min 1, max = `capacity.guests`
    * Children: min 0, max = `capacity.guests - adults`
    * Infants: min 0, max 5 (does not count toward guest limit)
    * Pets: disabled if property does not allow pets (`listing.houseRules.petsAllowed === false`).
* **Validation Rules:**
  * If `checkIn >= checkOut`: checkout automatically advances by +1 day.
  * Minimum stay rule: If listing requires minimum nights (e.g., 2 nights), dates within the threshold are invalid.
* **Submission Behavior:**
  * Clicking "Reserve" validates selected dates. In this client-side prototype, it displays a confirmation state or opens the checkout review drawer.

## 7. Accessibility (A11y) & Keyboard Navigation Contracts

1. **Focus Trapping:**
   * When `PhotoTour`, `Lightbox`, or `AmenitiesModal` is mounted, focus is trapped using keyboard hooks (`Tab` and `Shift+Tab` cycle between first and last focusable element).
2. **Scroll Lock:**
   * When modal overlays open, `document.body.style.overflow = 'hidden'` prevents background page scrolling.
3. **Esc Key Listeners:**
   * Overlay stack observes hierarchical closing: Lightbox closes first; secondary Esc closes Photo Tour; final Esc dismisses dropdowns.
4. **ARIA Invariance:**
   * Background container receives `inert` and `aria-hidden="true"` while full-screen modals are rendered.
